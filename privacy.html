Privacy Policy

Application: GC Backup

Effective date: 28 October 2026

1. Introduction

This Privacy Policy explains how GC Backup accesses and uses information when users authorize the application to perform backup operations involving Google Drive.

2. Information Accessed

Depending on the Google permissions granted and the operation requested, GC Backup may access Google Drive files, file contents, file names, metadata, and other information necessary to complete a backup. The application accesses only the data required for its implemented functionality and authorized operations.

3. How Information Is Used

Information accessed through Google is used to provide the backup functionality requested by the user, including identifying, reading, uploading, or managing files where supported by the application's granted permissions.

Google user data must not be used for advertising, sold, or used for unrelated purposes. Any additional processing must be consistent with the permissions granted and applicable Google API policies.

4. Storage and Sharing

Backup items are intended to be stored in the Google Drive account selected by the user. Google's own storage and security practices apply to data stored in Google Drive.

The application operator's access to file contents, OAuth tokens, logs, and other information depends on the application's technical implementation. Before using GC Backup, users should review any applicable disclosures about local storage, servers, temporary files, logs, or third-party services.

Google user data is not disclosed to third parties except as necessary to provide the requested functionality, with user consent, or as otherwise permitted or required by applicable law and Google API policies.

5. Data Retention and Deletion

Retention depends on where information is processed or stored by the application. Users can manage backup files in their Google Drive accounts. Revoking access to GC Backup does not automatically delete files already backed up to Google Drive.

To request deletion of information held by the application operator, contact the operator using the details below. Any request will be handled in accordance with applicable requirements and the application's actual retention practices.

6. Google Account Permissions

Users authorize GC Backup through Google's authorization process. Users can review or revoke the application's access through their Google Account's third-party connections page: Manage Google Account connections .

7. Security

Reasonable security measures should be used to protect information processed by GC Backup. No method of electronic storage or transmission can be guaranteed to be completely secure.

8. Children's Privacy

GC Backup is not specifically directed at children. Users should use the application in accordance with applicable age requirements and Google's terms.

9. Changes to This Policy

This policy may be updated to reflect changes in the application's functionality, data practices, or legal requirements. The latest version will be published on this page.

10. Contact

For privacy questions or data-related requests, contact: adlk_sa@googlegroups.com
